# 🚀 Beginner DOM Projects

A collection of beginner-friendly JavaScript DOM projects built to strengthen core front-end development skills. Each project demonstrates different DOM manipulation concepts using **HTML**, **CSS**, and **Vanilla JavaScript**.

This repository is designed for beginners who want to practice JavaScript by building small, interactive web applications.

---

## 📂 Projects Included

### 🎨 Background Color Changer

* Change the webpage background color dynamically.
* Learn DOM element selection and event handling.

### 🕒 Digital Clock

* Displays the current time in real time.
* Demonstrates JavaScript `Date` object and timers.

### 🔢 Counter App

* Increase, decrease, and reset the counter value.
* Learn button events and DOM updates.

### 📧 Email Validation

* Validate email addresses using JavaScript.
* Practice form handling and regular expressions.

### 🔐 Random Password Generator

* Generate secure random passwords instantly.
* Learn string manipulation and random number generation.

### 💬 Random Quote Generator

* Display random inspirational quotes with a button click.
* Practice arrays, objects, and DOM updates.

### 🎲 Tambola Number Generator

* Generate unique Tambola (Housie) numbers.
* Demonstrates randomness and preventing duplicate values.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/jillasrivardhan/Beginner-DOM-Projects.git
```

### Navigate to the project

```bash
cd Beginner-DOM-Projects
```

Open any `.html` file in your browser to run the corresponding project.
